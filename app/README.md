# Xovê — web

React 19 + TypeScript frontend, built with Vite.

- `npm run dev`: dev server; `/api` is proxied to the API on `localhost:8080`
- `npm test`: Vitest + Testing Library
- `npm run build`: production build in `dist/`

Real video comes from LiveKit (`livekit-client`); seats, the queue and which streams are live come from the API.
